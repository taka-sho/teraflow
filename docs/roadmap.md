# TeraFlow Roadmap

## Current Focus (v0.5.x)

- Stabilize discovery flow quality and reliability for GitHub Discussions.
- Improve release automation and template consistency.
- Raise confidence with coverage and regression hardening in CLI/workflows.

## Near Term (v0.6.0)

- i18n support and document/CLI UX improvements.
- Better agent provider operations (selection, fallback, diagnostics).
- Stronger CoDD lifecycle support from requirement intake to design traceability.

## Mid Term

- Expand V-model support around planning, impact, and implementation guidance.
- Improve collaboration ergonomics for AI-assisted review/implementation workflows.
- Continue hardening error catalogs, doctor checks, and CI guardrails.

## Done Recently

- v0.5.0: GraphRAG x CoDD integration and V-model SLCP-JCF pipeline expansion.
- v0.5.3-v0.5.10: discovery quality upgrades, release automation, and workflow fixes.
