### GraphRAG × CoDD 統合（新規）

- CoDD 文書群からナレッジグラフを自動構築
- 明示的依存関係（`depends_on`）と暗黙的関係（LLM 抽出エンティティ）の統合
- 要件変更の影響分析・トレーサビリティクエリ
- アーキテクチャ: Go CLI + Python subprocess、NetworkX + GraphML ストレージ
- Phase 1 (PR #128): `teraflow graph status/check/export`（Go完結）
- Phase 2 (PR #129-#134):
  - PR #129: Python パッケージ骨格
  - PR #130: エンティティ抽出（litellm）
  - PR #131: CoDD 取り込み + グラフ構築
  - PR #132: コミュニティ検出（Leiden/graspologic）
  - PR #133: Go ブリッジ + `graph build` CLI
  - PR #134: 統合テスト + `ci-graphrag.yml`

## マイグレーション

- `go install` で `@latest` を使用している場合、CLI 利用者側の追加変更は不要。
- GitHub Actions テンプレートは `teraflow setup actions --sync` で更新可能。
- 既存テンプレートで `@latest` 前提だった環境は、PR #125 の tag pinning 挙動を前提に運用する。
