AIと対話しながらソフトウェア開発ライフサイクルを管理するCLI。

## Installation

```bash
go install github.com/taka-sho/teraflow@latest
```

## 30-Second Quick Start

```bash
teraflow init --name "my-project" --non-interactive
teraflow status
```
